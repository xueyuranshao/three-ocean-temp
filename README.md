# three-ocean-temp
三维温度场
# 项目分析记录

## 当前目标
项目当前不是通用海洋场景演示，而是“海底背景 + 三维温度场整体折叠/抽拉展示”的可视分析原型。
后续修改默认应保持这个方向，除非需求明确改变。

## 当前代码结构

### `src/main.ts`
核心入口，当前所有 Three.js 场景逻辑都集中在这里。

主要内容：
- 创建 `Scene`、`PerspectiveCamera`、`WebGLRenderer`、`OrbitControls`
- 添加天空球、半球光和两盏方向光
- 通过程序噪声生成海底地形，并按高度写入蓝色系顶点颜色
- 用 `BoxGeometry` 创建完整三维温度体块，并给顶点写入温度伪彩色
- 通过滑块和方向按钮对整个温度体块做折叠/压缩，而不是单独抽出一层切片
- 额外绘制一个低透明度线框，跟随体块一起变化
- 运行时插入左下角中文控制面板 DOM
- 动画循环中更新控制器阻尼和场景渲染

关键函数/概念：
- `fbm()` / `smoothNoise()` / `ridgeNoise()`：生成海底地形噪声
- `terrainHeight()`：海底高度场
- `sampleRamp()`：温度伪彩色带采样
- `resetVolumeGeometry()`：恢复体块初始几何
- `resetVolumeColors()`：恢复体块初始颜色
- `updateTopSurfaceColor()`：顶部折叠模式下更新顶面颜色
- `applyFold()`：按当前方向和强度折叠温度体块

### `src/style.css`
负责：
- 页面背景
- 全屏 canvas
- 左下角控制面板样式

当前文件已按 `UTF-8` 保存，中文文本可正常显示。

## 当前视觉组成
- 背景：浅色天空球
- 中景：程序化海底地形
- 主视觉：有厚度的三维温度体块
- 交互点：体块支持三种折叠方向
  - `rtl`：右向左
  - `ltr`：左向右
  - `ttb`：上到下
- 辅助 UI：左下角控制面板、方向按钮和折叠强度读数

## 当前交互逻辑
- 滑块 `0% -> 100%` 控制折叠强度
- 左右折叠模式会直接改写 `BoxGeometry` 顶点位置，并给体块增加少量 `z` 向弯曲
- 上下折叠模式通过缩放体块高度实现压缩，同时重算顶面颜色
- 线框 `volumeFrame` 会同步跟随体块的尺寸和位置变化

## 已确认的约束
- 温度伪彩效果必须保留
- 表现重点是“三维温度场可视分析”
- 当前交互核心已经从“单层切片抽拉”变成“整体体块折叠”
- 后续问题和修改都以当前项目状态为基线
- 中文内容必须避免乱码，写文件时保持 `UTF-8`

## 当前实现与旧记录的差异
- 当前代码里已经没有独立水面网格和水面 Shader
- 当前代码里没有 `temperatureField()` 这一类三维采样函数，温度颜色主要按体块高度分布
- 当前代码里没有独立“右侧切片网格”，而是直接对整个温度体块做折叠变形

## 后续可继续演进的方向
- 把折叠体块进一步做成真正的剖切缺口，而不只是压缩/卷折形变
- 增加层号切换，不只控制整体折叠强度
- 给温度体块加入更真实的体内分布，而不是主要按高度着色
- 继续贴近参考图，补业务 UI、图例、面板和标注
- 如果接入真实 bathymetry/DEM，可替换当前程序化海底高度场
